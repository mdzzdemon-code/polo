# Le Paradoxe de l'Écho

RPG d'action 3D en développement sous Godot. Une Anomalie, coincée dans des
boucles temporelles de trois jours, tente de comprendre son passé et de
sauver un monde qu'elle ne connaît pas vraiment.

## Documentation

- [`docs/GDD.md`](docs/GDD.md) — Game Design Document : identité de
  l'Anomalie, systèmes (carnets, temps, dialogue, combat, mémoire,
  mots-clés...), personnages principaux, monde.
- [`docs/architecture.md`](docs/architecture.md) — architecture technique du
  projet Godot et état d'avancement.

## Prérequis

- Godot 4.3+ (rendu Forward+)

## Ouvrir le projet

Ouvrir ce dépôt comme projet dans Godot 4 (`project.godot` à la racine).
